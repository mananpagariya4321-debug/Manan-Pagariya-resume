# Manan Pagariya — Emergent-style resume website

This is a static recreation of the visual style and content structure of the Emergent preview. The full name "Manan Pagariya" is shown in the header and footer.

## Included
- `index.html` — all page content in crawlable HTML
- `style.css` — responsive navy, white, and muted-gold design
- `assets/manan-pagariya.jpg` — profile photo

## Publish for free with GitHub Pages
1. Open https://github.com/mananpagariya4321-debug/Manan-Pagariya-resume
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and the `assets` folder.
4. Click **Commit changes**.
5. Go to **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then click **Save**.
7. Your website should appear at `https://mananpagariya4321-debug.github.io/Manan-Pagariya-resume/`.

Privacy: phone number and home address are deliberately omitted. The page includes a meta description and searchable HTML text.
